# Short Video Operations Skills

A portable Agent Skills repository for multi-client short-video operations with Codex and Hermes Agent.

## Included capabilities

- Isolated client and project context
- Topic and content planning
- Script and time-coded storyboard production
- Provider-neutral avatar and generative-media planning
- Deterministic edit manifests
- Technical and editorial quality control
- Human approval gates
- Dry-run defaults for paid providers and publishing

## Safety defaults

- No paid API call without explicit authorization
- No publication without human approval
- No secrets in repository files
- Real footage preferred for factual product or repair evidence
- Every artifact tied to a client, project, content item, and version

## Start here

Team members should follow [docs/team-install.md](docs/team-install.md). Repository maintainers should run:

```text
python scripts/validate_workspace.py .
```

The example client and project contain no real customer data.
